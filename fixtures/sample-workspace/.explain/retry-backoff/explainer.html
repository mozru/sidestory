Four knobs

optionmeaning
retriesattempts after the first one
baseMsceiling of the first wait
maxMscap on any single wait
shouldRetryoptional: give up early on errors that won't go away

How long to wait

The ceiling doubles every attempt until maxMs; the actual wait is a random point below it. Randomness spreads clients out so they don't retry in lockstep.

The loop

Each turn calls fn(attempt). Success returns at once; a failure waits a jittered delay and tries again.

  1. attempt 0 fails → wait up to 100 ms
  2. attempt 1 fails → wait up to 200 ms
  3. attempt 2 succeeds → return its value
When it gives up: when shouldRetry says no, or after retries extra attempts. The last error is rethrown unchanged.
