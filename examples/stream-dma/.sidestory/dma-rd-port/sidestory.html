The simplest block on the data path: a request register, a beat counter, and wires.

Inside dma_rd_port

Response data goes straight from the bus into the FIFO; only the handshake is logic. Click a block to see its code.

Ready only while a burst is open and the FIFO has room

rd_rsp_ready = (left_q != 0) && !fifo_full. A beat moves when the bus says valid and we say ready; that is also the FIFO's push, and the FSM's fifo_push count.

The request register

start (dma_ctrl's rd_start) loads address and length and raises rd_req_valid, which stays up until rd_req_ready. left_q counts the response beats still expected; any beat with an error makes the burst's err sticky.

busy, done, err

done pulses with the last beat, err alongside it; busy covers the whole burst, so the FSM's ERROR state can wait for it to finish.
