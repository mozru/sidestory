Six registers on a simple word-addressed bus. The engine reads its configuration from here and reports back through two strobes.

Register map

offsetnamebits
0x00CTRL[0] start (write 1), [1] irq_en
0x04STATUS[0] busy, [1] done (W1C), [2] error (W1C)
0x08SRCsource byte address
0x0CDSTdestination byte address
0x10LENlength in bytes
0x14ERR1 zero length, 2 read, 3 write

Writes, start, and the outcome

A write to CTRL with bit 0 set while idle is the start pulse. SRC, DST and LEN ignore writes while busy, so a running transfer's configuration can't change under it. start clears the previous outcome; done_set and err_set from dma_ctrl set the new one.

Read mux

A plain combinational mux on the word address; unused bits read 0.

The interrupt

A level: irq_en && (done || error). Software acknowledges by writing 1s to STATUS, or by starting the next transfer.
